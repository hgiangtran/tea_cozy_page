# The Tea Cozy

A responsive landing page for a fictional tea shop, built with semantic HTML5 and custom CSS. 

*Project developed as part of the Codecademy Front-End Engineer Path.*

## 📌 Overview

A simple landing page with a navigation bar, featured products section, and store locations.

### Key Sections:
- **Navigation Bar:** Fixed header with smooth-scrolling links.
- **Our Mission:** Hero section with full-width background imagery and overlay copy.
- **Tea of the Month:** Responsive photo-and-caption display for featured selections.
- **Locations:** Card-based store locator displaying addresses across different branches.
- **Contact & Footer:** Business hours, inquiries, and copyright notice.

## 🛠️ Built With

- **HTML5:** Semantic structure (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3:** Custom styling using Flexbox for alignment, fixed positioning, and custom typography.
